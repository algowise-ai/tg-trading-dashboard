# TG Trading · FX/XAU

Public **static** snapshot of the TG Trading (FX/XAU CFD tip) paper dashboard.

- Backtest vs Live demo, paper fund, channel scores — **paper only**, no live broker.
- No API keys, Telegram sessions, or secrets.
- Rebuilt on Mac Mini and pushed to GitHub Pages (`*.github.io`, no custom domain).

## Local preview

Open `index.html` in a browser (keep `static/` and `api/` beside it).
